Полная инструкция: что вы получите и как подключить салон

Beaty — платформа брендированных Telegram-ботов для записи. Клиенты пишут вашему боту, а не агрегатору с конкурентами рядом. Запись 24/7, напоминания, веб-кабинет для управляющего и мастеров — одно ядро для чата и сайта.

Что получает салон

  • Собственный бот в Telegram под именем и брендом заведения.
  • Онлайн-запись: услуги, мастер, время, «Мои записи» для клиента.
  • Расписание дня, дашборд, шаблоны напоминаний в Telegram.
  • Витрина салона: портфолио, карта, ссылка и QR для Яндекс.Карт и соцсетей.

Как начать в Telegram

  1. Откройте @beaty_welcome_agent и нажмите Start (или отправьте /start).
  2. Шаг 1. Пришлите название бизнеса — так салон появится в платформе.
  3. Шаг 2. Создайте бота в @BotFather и отправьте токен одним сообщением. Сообщение с токеном бот удалит после обработки.
  4. После подключения вы получите Public ID салона. Откройте бота салона: в чате появится кнопка «Открыть» для записи и кабинета (или запись через /start в чате).
  5. Если салон уже был подключён, бот попросит только актуальный токен — например, после Revoke в BotFather.

Подписка и оплата

Доступ к Beaty — по модели SaaS-подписки: платёж вносит само заведение (салон), как правило с ежемесячным автоматическим списанием. После регистрации в платформенном боте и активации оплаченной подписки функции доступны дистанционно через интернет на протяжении расчётного периода.

Конечные клиенты салона за пользование записью и уведомлениями через Beaty исполнителю платформы не платят — услуги красоты оказываются салоном по своим ценам. Тариф, оферта и порядок оплаты доводятся в боте при подключении.

Поддержка

Все вопросы по подключению, токену, подписке и доступу — в переписке с @beaty_welcome_agent. Для проверки статуса платформы у бота есть команда /status.

Описание услуги. Предоставление доступа к программному комплексу Beaty (SaaS) для салонов красоты, барбершопов и студий: онлайн-запись клиентов, расписание мастеров, веб-кабинет управляющего, напоминания и Telegram-бот салона. Платёж за подписку вносит само заведение (салон) по модели с ежемесячным автоматическим списанием. Конечные клиенты салона за пользование записью и уведомлениями через Beaty исполнителю платформы не платят — услуги парикмахерские, косметологические и иные оказываются салоном по своим ценам.

Условия оказания (выдачи) услуги. Доступ предоставляется дистанционно через сеть Интернет после регистрации бизнеса в платформенном боте и активации оплаченной подписки. Услуга считается оказанной на протяжении оплаченного расчётного периода при наличии технической возможности пользоваться функционалом. Срок действия — до окончания оплаченного месяца; продление — при успешном ежемесячном списании либо ручной оплате по тарифу. Порядок оплаты, изменения тарифа, приостановки доступа при неоплате и возврата средств определяются офертой и правилами, доведёнными при подключении в боте.
