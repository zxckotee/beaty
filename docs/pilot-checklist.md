# Чеклист пилота MVP

## Регистрация и запись

- [ ] Владелец проходит онбординг в платформенном боте и подключает токен
- [ ] Клиент `/start` → согласие → контакт → Mini App
- [ ] Запись: услуга → мастер → слот → hold → confirm
- [ ] Перенос и отмена в пределах дедлайна
- [ ] Офлайн-клиент менеджером, merge по телефону при входе в бота

## Напоминания

- [ ] Подтверждение записи сразу после confirm
- [ ] Напоминание за 24 ч с кнопкой «Подтверждаю»
- [ ] Напоминание за 2 ч, тихие часы не будят ночью

## Персонал

- [ ] Менеджер видит календарь и создаёт запись вручную
- [ ] Мастер: мой день, arrived / completed / no_show
- [ ] Форс-мажор: клиент получает варианты, менеджер видит нерешённые

## Метрики

- SQL view или экспорт: записи через бота, no-show rate до/после, подтверждения за 24 ч
