# Бизнес-модель, онбординг, юридические вопросы, метрики

Допущения: стартовый рынок — Россия и СНГ, продаём SaaS по подписке, первые клиенты — мастера-одиночки и небольшие салоны. Цифры ниже — гипотезы для проверки, а не финальные решения.

## 1. Конкуренты и отличие

| Альтернатива | Сильная сторона | Наше отличие |
| --- | --- | --- |
| Администратор + мессенджер + тетрадка | Привычно, «по-человечески» | Запись 24/7, напоминания, нет потерянных клиентов, не нужен отдельный сотрудник |
| DIKIDI | Бесплатный, есть каталог-агрегатор | Свой бренд вместо агрегатора с конкурентами рядом, всё внутри Telegram |
| YCLIENTS, Altegio | Полноценная CRM, склад, кассы | Проще и быстрее в запуске, дешевле, клиенту не нужно ставить приложение или заходить на сайт |
| Свой бот на заказ | Полная кастомизация | Готово за 5 минут, поддерживается и развивается без затрат бизнеса |

Формулировка ценности для продаж: **«Свой бот для записи под вашим брендом за 5 минут. Меньше неявок, больше повторных визитов, без администратора на телефоне»**.

## 2. Монетизация

Тарифы зависят от числа активных мастеров — это понятно бизнесу и растёт вместе с ним.

| Тариф | Для кого | Что входит |
| --- | --- | --- |
| Старт (бесплатно) | 1 мастер | Запись, напоминания, базовый бренд, подпись «Сделано на Beaty» в боте |
| Мастер | 1 мастер | Без подписи, отзывы, «пора снова», курсы, акции |
| Салон | 2–10 мастеров | Всё выше + роли персонала, финансы и выплаты, дайджесты, лист ожидания |
| Сеть | Филиалы, 10+ мастеров | Филиалы, ресурсы, импорт данных, приоритетная поддержка, отдельный инстанс по запросу |

- Пробный период платного тарифа — 14–30 дней без карты.
- Годовая оплата со скидкой.
- Подпись «Сделано на Beaty» на бесплатном тарифе — бесплатный канал привлечения: клиенты салонов сами видят продукт и часто сами работают мастерами.
- Дополнительные платные опции позже: ИИ-ассистент, SMS-напоминания для клиентов без Telegram, онлайн-предоплата (комиссия или фикс), брендированные QR-материалы.
- Реферальная программа для бизнесов: месяц бесплатно за приведённый салон.

### Неоплата подписки

Клиенты салона не должны страдать из-за проблем с оплатой:

1. За 7 и за 1 день до окончания — напоминания владельцу в платформенном боте.
2. После окончания — льготный период N дней: всё работает, владелец видит баннер.
3. Затем новые записи закрываются (клиент видит «запишитесь по телефону …»), но существующие записи и напоминания по ним работают до конца.
4. Данные хранятся ещё 90 дней, владелец может выгрузить их в любой момент.

## 3. Онбординг бизнеса

Цель — первая реальная запись в течение дня после регистрации.

1. Владелец находит платформенный бот (лендинг, реклама, подпись в чужом боте, рекомендация).
2. Пошаговая инструкция по BotFather со скриншотами или коротким видео: как создать бота, какое имя выбрать, как поставить аватар.
3. Владелец присылает токен — бот проверяет его и подключает за секунды.
4. Мастер настройки в Mini App:
   - тип бизнеса (барбершоп, маникюр, косметология, тату…) — подставляет **шаблон каталога услуг** с типовыми длительностями и интервалами «пора снова», который остаётся только поправить;
   - график из готовых вариантов (2/2, 5/2, свой);
   - бренд: логотип, цвет, тон общения;
   - мастера: приглашение по ссылке — мастер сам открывает её в Telegram и заполняет профиль.
5. Материалы для запуска: ссылка для Instagram, QR-код для печати, текст сообщения «теперь записывайтесь через бота» для текущих клиентов.
6. Импорт текущих клиентов и будущих записей из Excel или CSV, позже — из YCLIENTS и DIKIDI.
7. Через 3 и 7 дней — проверка: если записей нет, платформенный бот подсказывает, что сделать, и предлагает помощь поддержки.

## 4. Юридические вопросы

Требует проверки юристом до запуска.

- **152-ФЗ «О персональных данных»**:
  - Бизнес — **оператор** персональных данных своих клиентов, мы — **обработчик** по поручению оператора. Нужен договор-поручение (входит в оферту для бизнеса).
  - При регистрации клиент даёт согласие на обработку данных, с ссылкой на политику конфиденциальности бизнеса. Для бизнеса без своей политики даём шаблон.
  - Данные граждан РФ первично записываются и хранятся в базах на территории РФ — выбираем российского хостинг-провайдера.
  - Право клиента на удаление данных — реализовано в профиле.
  - Подсказываем бизнесу о необходимости уведомить Роскомнадзор об обработке персональных данных.
  - Фото клиентов и фото «до/после» — только с отдельного согласия.
- **Реклама** (38-ФЗ): маркетинговые рассылки — только тем, кто дал на них отдельное согласие. Отписка в один клик.
- **Онлайн-оплата** (54-ФЗ): при предоплате нужен чек — используем провайдера с облачной кассой (например, ЮKassa). Ответственность за чек — на бизнесе, мы даём настройку.
- **Оферта для бизнеса**: условия подписки, SLA, ограничение ответственности, порядок выгрузки и удаления данных при уходе.
- **Отзывы**: правила модерации публикуются заранее, бизнес не может удалять негативные отзывы — это прописано в оферте.

## 5. Поддержка

- Чат поддержки прямо в платформенном боте.
- База знаний и короткие видео по типовым задачам.
- Статус-страница и оповещения владельцев в платформенном боте при сбоях.

## 6. Метрики

**Для бизнеса** (показываем в его отчётах — это доказательство ценности продукта):

- Количество записей через бота и доля записей вне рабочего времени.
- Доля неявок до и после подключения.
- Доля подтверждённых визитов.
- Возвраты: доля клиентов, пришедших повторно в течение интервала услуги, и записи из напоминаний «пора снова».
- Загрузка мастеров (%) и средний чек.
- Записи по источникам (Instagram, QR, рефералы).

**Для нас:**

- Активация: доля бизнесов, получивших первую запись за 7 дней.
- Воронка клиента: `/start` → регистрация → выбор услуги → выбор слота → подтверждённая запись.
- Удержание бизнесов по месяцам, отток и его причины.
- Конверсия из бесплатного тарифа в платный.
- MRR, ARPA, стоимость привлечения.
- Количество бизнесов, пришедших через подпись «Сделано на Beaty».
