# Bot-only Beauty Record

## Два бота

- **Платформенный бот (Beauty Record)** — владелец создаёт бизнес, передаёт токен из @BotFather.
- **Бот бизнеса** — клиенты, специалисты и менеджер работают только в чате этого бота (Reply/Inline + FSM). Отдельного сайта и Mini App нет.

## Роли

| Роль | Как получает |
| --- | --- |
| Менеджер (включая owner) | Owner автоматически при подключении токена; второй менеджер — по invite от owner |
| Специалист | Менеджер создаёт профиль, специалист переходит по ссылке `?start=inv_…` |
| Клиент | `/start`, телефон через `request_contact` |

Специалист может существовать без Telegram (офлайн-профиль): записи к нему возможны, уведомления в Telegram — нет.

## Приглашение специалиста

1. Менеджер: «Команда» → добавить → имя, фото, описание, специализация.
2. Бот выдаёт ссылку `https://t.me/<bot>?start=inv_<token>`.
3. Специалист нажимает Start — аккаунт привязывается к профилю.

По `@username` пригласить нельзя: Telegram отдаёт `user_id` только после контакта с ботом.

## Менеджер в боте

- Сегодня: лента записей, фильтр по дням, действия на карточке.
- Команда: список, invite, назначение менеджера (owner).
- Услуги: CRUD через FSM, шаблон каталога barber.
- Записать клиента: ручная запись offline-клиента.
- Ещё: нерешённые переносы, название салона, URL политики.

## API

Публичный REST (`/api/v1`) по умолчанию выключен (`ENABLE_PUBLIC_API=false`). Остаются `/health`, `/ready`, webhook-шлюз.

## Не в MVP bot-only

Маркетинг и финансы в чате, веб-ресепшен, S3 для фото (используем Telegram `file_id`).
